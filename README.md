# 📚 BookBuddy – Personal Library Manager

BookBuddy is a simple and responsive web application for managing your personal book collection. It helps users organize books, track borrowed books, and monitor reading goals through an easy-to-use interface.
# 🌐 Live Demo

🔗 **Website:** https://ashwin-more.github.io/bookbuddy-personal-library/

---
## ✨ Features

- 📖 Add, edit, and delete books
- 🔍 Search and filter books
- 📚 Organize your personal library
- 🤝 Track borrowed books
- 🎯 Set and monitor reading goals
- 📊 Dashboard with library overview
- 🌙 Dark Mode UI
- 📄 Export data to Excel and PDF
- 🔐 User Login Authentication

## 🛠️ Tech Stack

**Frontend**
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

**Libraries**
- SheetJS (XLSX)
- jsPDF
- jsPDF AutoTable

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/BookBuddy.git
```

### 2. Open the Project

```bash
cd BookBuddy
```

### 3. Run the Application

Simply open `login.html` or `index.html` in your web browser.

No additional installation or server setup is required.
